🏨 Hotel Bookings Analysis
    📊 Exploratory Data Analysis of hotel booking data to understand booking patterns, customer behavior, cancellations, pricing, and hotel demand.

🎯 Project Objectives
    📅 Analyze booking trends over time
    🏨 Compare City Hotel vs Resort Hotel
    ❌ Understand booking cancellations
    👥 Analyze customer and guest patterns
    💰 Study pricing and stay duration
    📊 Identify factors affecting hotel demand

🛠️ Tools & Technologies
    🐍 Python • 🐼 Pandas • 🔢 NumPy • 📊 Matplotlib • 📈 Seaborn • 📓 Jupyter Notebook
