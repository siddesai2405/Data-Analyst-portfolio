Hotel Bookings Data Analysis

About the Project
This project is based on a hotel bookings dataset. The main goal was to understand the booking data, clean it properly, explore different patterns, and find useful insights from the data.
I worked on this project as part of my Data Analytics learning journey. It helped me get more comfortable with Python, data cleaning, exploratory data analysis, and data visualization.

Dataset
The dataset contains information about hotel reservations, including details such as:
    Hotel type
    Booking status
    Arrival date
    Number of guests
    Number of nights
    Meal type
    Country
    Market segment
    Room information
    Previous bookings
    Average daily rate
    Cancellation status
    
What I Did
In this project, I went through the complete basic data analysis process.

  1. Data Understanding
  I first explored the dataset to understand:
      Number of rows and columns
      Data types
      Different categories
      Missing values
      Duplicate records
      Basic statistics
  
  2. Data Cleaning
  Before performing the analysis, I cleaned the dataset by:
      Checking and handling missing values
      Removing duplicate records where required
      Checking incorrect or inconsistent values
      Converting data into appropriate formats
      Handling outliers where necessary
  
  3. Exploratory Data Analysis
  After cleaning the data, I explored different questions related to hotel bookings.
  Some of the areas I looked at were:
      Which type of hotel receives more bookings?
      How many bookings get cancelled?
      Which countries contribute the most bookings?
      Which months have more bookings?
      How long do guests usually stay?
      Which market segments generate more bookings?
      How does the average daily rate change?
      What factors are related to booking cancellations?
  
  4. Data Visualization
  I used different visualizations to make the patterns in the data easier to understand.
  Some of the charts include:
      Bar charts
      Count plots
      Histograms
      Box plots
      Line charts
      Heatmaps
