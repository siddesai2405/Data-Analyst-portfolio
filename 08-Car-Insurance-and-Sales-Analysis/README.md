Car Insurance and Sales Data Analysis



Project Overview

This project focuses on analyzing insurance, vehicle, sales, service history, and ownership datasets to identify patterns and generate meaningful insights using SQL and Power BI.



Tools and Technologies

\- SQL: Data querying and analysis

\- Power BI: Interactive dashboard and data visualization

\- CSV: Structured datasets for analysis



Project Files

\- Car\_Data.csv — Vehicle data

\- Insurance\_data.csv — Insurance data

\- Owners\_data.csv — Vehicle ownership data

\- Sales\_data.csv — Sales data

\- Service\_History.csv — Service history data

\- Power BI.pbix — Power BI dashboard

\- SQLQuery.sql — SQL analysis queries



Key Objectives

\- Explore and analyze multiple datasets.

\- Use SQL to query and investigate data.

\- Present findings through an interactive Power BI dashboard.
