🛒 E-commerce Data Analysis | Amazon Products Sales Dashboard
	An e-commerce data analytics and business intelligence project using Excel and Power BI to analyze product sales, category performance, sales trends, and customer reviews.

👨‍💻 Project Overview
	This project focuses on analyzing Amazon product data to understand sales performance, product category contribution, customer reviews, and product-level trends.
The objective is to transform product-level data into meaningful business insights and present them through an interactive Power BI dashboard.
The dashboard provides an overview of sales performance using KPI cards, monthly and weekly sales trends, product category comparisons, and top-performing products based on sales and customer reviews.

🎯 Business Problem
	E-commerce businesses need to understand which products and categories contribute most to sales, how sales performance changes over time, and which products receive the highest customer engagement.
This project organizes Amazon product information into an interactive dashboard to support product performance analysis and business reporting.

Business Questions Answered
	💰 What are the Year-to-Date (YTD) and Quarter-to-Date (QTD) sales?
📅 How do sales change across different months?
📊 How does weekly sales performance vary?
🏷️ Which product categories contribute the most to total sales?
🛍️ Which five products generate the highest YTD sales?
⭐ Which products receive the highest number of customer reviews?
📦 How can sales performance be explored using product category and shipment filters?
🔍 How can users interactively filter and reset dashboard selections?

Download or clone this repository.
Install Microsoft Power BI Desktop.
Open Amazon_Combined_Data.xlsx to inspect the dataset.
Open DA_PROJECT.pbix in Power BI Desktop.
If required, update the Excel data source path in Power BI.
Refresh the dataset to load the data.
Explore the dashboard using product category, quarter, and shipment filters.
