E-commerce Data Analysis



An e-commerce analytics project using Excel and Power BI to explore combined Amazon-related data and present insights through an interactive dashboard.



Tools Used

\- Microsoft Excel

\- Power BI

\- Data Analysis and Visualization



Project Files

\- `Amazon\_Combined\_Data.xlsx` — Combined dataset

\- `DA\_PROJECT.pbix` — Power BI dashboard

\- `Amazon Background.jpg` — Background image

\- `amazon-logo-background-amazon-logo-white-plant-peel-sweets-food-transparent-png-1465048.png` — Amazon logo image

\- `amazon-logo-transparent-116589592147fnz0oo5ct.png` — Transparent Amazon logo



Objective

Explore e-commerce data and present useful information through a Power BI dashboard to support data-driven analysis.



How to Explore

1\. Open `Amazon\_Combined\_Data.xlsx` to review the dataset.

2\. Open `DA\_PROJECT.pbix` in Power BI Desktop.

3\. Explore the dashboard visuals and available insights.
