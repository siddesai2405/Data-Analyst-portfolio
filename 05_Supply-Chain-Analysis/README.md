Supply Chain Analysis



An exploratory data analysis project focused on understanding supply chain operations using Python and data analysis techniques.



Tools Used

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Jupyter Notebook



Project Files

\- `Supply Chain Analysis.ipynb` — Jupyter Notebook for analysis

\- `DataCoSupplyChainDataset.csv` — Main supply chain dataset

\- `DescriptionDataCoSupplyChain.csv` — Dataset field descriptions



Objective

Explore supply chain data to identify operational patterns, examine dataset trends, and support data-driven business insights.



How to Explore

1\. Install the required Python libraries.

2\. Open `Supply Chain Analysis.ipynb` in Jupyter Notebook.

3\. Update the dataset paths if necessary.

4\. Run the notebook cells.
