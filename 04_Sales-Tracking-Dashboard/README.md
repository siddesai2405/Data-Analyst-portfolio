Sales Tracking Dashboard



A data analysis project combining Python, SQL, Excel, and Power BI to explore sales data and build a dashboard for business insights.



Tools Used

\- Python

\- SQL

\- Power BI

\- Excel

\- Jupyter Notebook



Project Files

\- `Cleaning.ipynb` — Data cleaning and preparation

\- `sales\_raw\_500.xlsx` — Raw sales dataset

\- `sales\_cleaned.csv` — Cleaned sales dataset

\- `Sales Tracking Dashboard (Python + SQL + Power BI + Excel).pbix` — Power BI dashboard

\- `SQL\_Commands/` — Supporting SQL files and screenshots



Objective

Prepare sales data for analysis and present useful sales information through a Power BI dashboard.



How to Explore

1\. Open `Cleaning.ipynb` in Jupyter Notebook.

2\. Review the raw and cleaned datasets.

3\. Open the `.pbix` file in Power BI Desktop to explore the dashboard.
